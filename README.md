# EzWoW-DungeonRouteGuide

## English

**Dungeon maps, boss routes, and quest guidance** for WoW Forever (Interface 16001).

- Install the `EzWoW-DungeonRouteGuide` addon folder under `Interface/AddOns/`.
- The complete source distribution includes features, settings, changelog and license information.
- In-game compatibility still requires testing.

## 한국어

WoW Forever(Interface 16001)용 **던전 지도, 보스 경로 및 퀘스트 안내** 애드온입니다.

- `EzWoW-DungeonRouteGuide` 폴더를 `Interface/AddOns/`에 설치하세요.
- 전체 소스 패키지에 기능 설명, 설정, 변경 이력 및 라이선스가 포함되어 있습니다.
- 실제 게임 내 호환성은 추가 검증이 필요합니다.
